<h2><a href="https://www.geeksforgeeks.org/problems/shortest-substring-containing-all-vowels/1">Shortest Substring Containing all Vowels</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">You are given two strings, </span><strong><span style="font-size: 18.6667px;">s1</span></strong><span style="font-size: 18.6667px;"> and </span><strong><span style="font-size: 18.6667px;">s2</span></strong><span style="font-size: 18.6667px;">, where s1 contains </span><span style="font-size: 18.6667px;">distinct lowercase vowels</span><span style="font-size: 18.6667px;"> (a, e, i, o, u), and s2 contains </span><span style="font-size: 18.6667px;">lowercase English letters</span><span style="font-size: 18.6667px;">. Your task is to find the </span><span style="font-size: 18.6667px;">length</span><span style="font-size: 18.6667px;"> of the </span><span style="font-size: 18.6667px;">shortest</span><span style="font-size: 18.6667px;"> contiguous </span><span style="font-size: 18.6667px;">substring </span><span style="font-size: 18.6667px;">within s2 that contains all the </span><span style="font-size: 18.6667px;">vowels</span><span style="font-size: 18.6667px;"> present in s1 at least once, in any order.</span></p>
<p><span style="font-size: 18.6667px;"><strong>Note:</strong>&nbsp;If there is no such substring in s2, return <strong>-1</strong>.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>s1 = "ae", s2 = "acbaudeq"
<strong>Output: </strong>4<strong>
Explanation: </strong>The shortest substring of "acbaudeq" that contains both vowels 'a' and 'e' from s1 = "ae" is "aude", which has length 4.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>s1 = "iou", s2 = "iuixoiu"
<strong>Output: </strong>3<strong>
Explanation: </strong>The shortest substring of "iuixoiu" that contains all vowels 'i', 'o', and 'u' from s1 = "iou" is "oiu", which has length 3.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>s1 = "aeiou", s2 = "uoiee"
<strong>Output: </strong>-1<strong>
Explanation: </strong>The string s2 = "uoiee" is missing the vowel 'a' from s1 = "aeiou", so no substring can contain all required vowels, and the answer is -1.</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;<code>sliding-window</code>&nbsp;<code>Hash</code>&nbsp;
