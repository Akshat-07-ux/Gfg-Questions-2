<h2><a href="https://www.geeksforgeeks.org/problems/sort-last-m-elements--155156/1?page=9&category=Sorting&sortBy=submissions">Sort a Prefix Sorted Array</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an array <strong>arr[]</strong> of length <strong>n + m</strong>, where the first <strong>n</strong> elements are already sorted, sort the whole array.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 3, 6, 19, 11, 16]</span><span style="font-size: 18px;">, m = 3
<strong>Output: </strong>[1, 3, 6, 11, 16, 19]<br></span><strong><span style="font-size: 14pt;">Explanation: </span></strong><span style="font-size: 18.6667px;">Sorting the last 3 elements [19, 11, 16] and merging with the first 3 sorted elements [1, 3, 6] gives [1, 3, 6, 11, 16, 19].</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong></span><span style="font-size: 18px;">arr[] = [10, 20, 30, 5, 15, 25], n = 3, m = 3
</span><span style="font-size: 18px;"><strong>Output:</strong> [5, 10, 15, 20, 25, 30]
<strong>Explanation:</strong> First 3 elements [10, 20, 30] are sorted but larger than last 3 elements [5, 15, 25]. After sorting the entire array becomes [5, 10, 15, 20, 25, 30].</span></pre>
