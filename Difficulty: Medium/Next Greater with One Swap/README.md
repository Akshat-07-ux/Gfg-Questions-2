<h2><a href="https://www.geeksforgeeks.org/problems/next-higher-number-in-one-swap1703/1">Next Greater with One Swap</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given a non-negative number num<strong> </strong>represented as a string, apply at <strong>most one</strong> swap operation on any two of its digits to obtain the next higher number. </span></p>
<p><span style="font-size: 18px;">If it is impossible to form a higher number, return "<strong>-1</strong>".</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>num = "768"
<strong>Output:</strong> "786"
<strong>Explanation</strong>: 786 is next higher number that we can get.
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>num = "333"
<strong>Output:</strong> "-1"
<strong>Explanation</strong>: There is no higher number than 333. 
</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ |num| ≤ 10<sup>5</sup></span></p>
<p><span style="font-size: 18px;">|num| denotes the length of the string num.</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;<code>Numbers</code>&nbsp;
