<h2><a href="https://www.geeksforgeeks.org/problems/previous-number-in-one-swap5707/1">Previous Number in One Swap</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt; font-family: Arial, sans-serif; color: #000000; background-color: transparent; font-weight: 400; font-style: normal; font-variant: normal; text-decoration: none; vertical-align: baseline; white-space: pre-wrap;">Given a string <strong>s</strong> representing a non-negative integer, find the <strong>largest</strong> number smaller than s, that can be obtained by performing at most one swap of two digits. If no such number can be formed, return "<strong>-1</strong>".</span></p>
<p><span id="docs-internal-guid-d4fe7bf4-7fff-fdbb-2a06-e8bf5795f1a4" style="font-size: 14pt;"></span></p>
<p><span style="font-size: 14pt; font-family: Arial, sans-serif; color: #000000; background-color: transparent; font-weight: 400; font-style: normal; font-variant: normal; text-decoration: none; vertical-align: baseline; white-space: pre-wrap;"><strong>Note:</strong> The resulting number must not contain leading <strong>zeros</strong>. </span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input : </strong><span style="font-size: 18px;">s = "12435"
</span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">"12345" <br></span><strong><span style="font-size: 18px;">Explanation: </span></strong></span><span style="font-size: 18px;">Swap 4 and 3 to get 12345, which is the largest smaller number possible using one swap.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "12345"
<strong>Output: </strong>"-1"
<strong>Explanation: </strong></span><span style="font-size: 14pt;">Digits are in increasing order, so no smaller number can be formed.</span></pre>
