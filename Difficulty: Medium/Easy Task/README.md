<h2><a href="https://www.geeksforgeeks.org/problems/easy-task--170647/1?page=7&category=Strings&sortBy=submissions">Easy Task</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given a lowercase string <strong>s</strong> of length <strong>n</strong> and <strong>q</strong> queries, process the queries in order. </span></p>
<p><span style="font-size: 14pt;">There are two types of queries:</span></p>
<ul>
<li><span style="font-size: 14pt;"><strong>Type 1</strong>: ["<strong>1</strong>", <strong>index</strong>, <strong>ch</strong>]</span><br><span style="font-size: 14pt;">Update the character at position index in s to ch.</span></li>
<li><span style="font-size: 14pt;"><strong>Type 2</strong>: ["<strong>2</strong>", <strong>left</strong>, <strong>right</strong>, <strong>k</strong>]</span><br><span style="font-size: 14pt;">Consider the substring s[left...right] (both inclusive). Return the k-th lexicographically largest character in the substring after sorting its characters in descending order. Duplicate characters are counted separately (i.e., find the k-th character, not the k-th distinct character).</span></li>
</ul>
<p><span style="font-size: 14pt;">Return an array containing the answers to all Type 2 queries in the order they appear.</span></p>
<p><span style="font-size: 14pt;"><strong>Note:</strong> All indices are 0-based.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong style="font-size: 14pt;">Input:</strong><span style="font-size: 14pt;"> s</span><strong style="font-size: 14pt;"> </strong><span style="font-size: 14pt;">= "abab", queries[][] = [["1", "2", "d"], ["2", "1", "3", "1"]]
</span><strong style="font-size: 14pt;">Output:</strong><span style="font-size: 14pt;"> ["d"]
</span><strong style="font-size: 14pt;">Explanation: </strong><span style="font-size: 18.6667px;">After the first query, s becomes "abdb".
The substring from index 1 to 3 is "bdb". <br>Sorting it in descending order gives "dbb", so the 1st largest character is 'd'.</span></span></pre>
<pre><span style="font-size: 14pt;"><strong style="font-size: 14pt;">Input:</strong><span style="font-size: 14pt;"> s</span><strong style="font-size: 14pt;"> </strong><span style="font-size: 14pt;">= "aaa", queries[][] = [["1", "1", "e"], ["1", "2", "c"], ["2", "1", "2", "2"]]
</span><strong style="font-size: 14pt;">Output: </strong><span style="font-size: 14pt;">["c"]
</span><strong style="font-size: 14pt;">Explanation: </strong><span style="font-size: 18.6667px;">After the updates, s becomes "aec".
The substring from index 1 to 2 is "ec". <br>Sorting it in descending order gives "ec", so the 2nd largest character is 'c'.</span></span></pre>
<p><span style="font-size: 14pt;"><strong>Constraints:<br></strong></span><span style="font-size: 18.6667px;">1 ≤ n ≤ 5 * 10<sup>4</sup><br></span><span style="font-size: 18.6667px;">1 ≤ q ≤ 10<sup>5</sup><br></span><span style="font-size: 18.6667px;">0 ≤ left ≤ right &lt; n<br></span><span style="font-size: 18.6667px;">0 ≤ index &lt; n<br></span><span style="font-size: 18.6667px;">1 ≤ k ≤ right - left + 1<br></span><span style="font-size: 18.6667px;">'a'&nbsp;</span><span style="font-size: 18.6667px;">≤</span><span style="font-size: 18.6667px;"> s[i], ch&nbsp;</span><span style="font-size: 18.6667px;">≤</span><span style="font-size: 18.6667px;">&nbsp;'z'<br></span><span style="font-size: 18.6667px;">The sum of n over all test cases does not exceed 5 * 10<sup>4&nbsp;</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Segment-Tree</code>&nbsp;<code>Advanced Data Structure</code>&nbsp;<code>Strings</code>&nbsp;
