<h2><a href="https://www.geeksforgeeks.org/problems/largest-gap/1?page=10&category=Sorting&sortBy=submissions">Largest Gap in Intervals</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given two arrays <strong>start[] </strong>and <strong>end[]</strong> of size <strong>n</strong>, where the i-th car is travelling during the time interval <strong>[start[i], end[i]]</strong>, find the maximum duration for which no car is travelling. </span><span style="font-size: 18.6667px;">If all travel intervals overlap or touch each other such that there is no time gap between any two consecutive travel periods, return 0.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>start[] = [20, 18, 4]</span><span style="font-size: 18px;">, </span><span style="font-size: 18px;">end[] = [25, 20, 15]</span>
<span style="font-size: 18px;"><strong>Output: </strong>3</span>
<span style="font-size: 18px;"><strong>Explanation:</strong> </span><span style="font-size: 18px;"><span style="font-size: 18px;">The intervals are </span></span><span style="font-size: 18px;"><span style="font-size: 18px;">(20, 25), (</span></span><span style="font-size: 18px;"><span style="font-size: 18px;">18, 20) and (</span></span><span style="font-size: 18px;"><span style="font-size: 18px;">4, 15). No car is traveling between times 15 and 18, so the largest gap is 3.</span></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>start[] = [3, 1]</span><span style="font-size: 18px;">, </span><span style="font-size: 18px;">end[] = [5, 5]</span>
<span style="font-size: 18px;"><strong>Output: </strong>0<br><strong>Explanation:</strong> Both intervals (3, 5) and (1, 5) overlap and cover the entire range from 1 to 5. Hence no gap exists.</span></pre>
<p><span style="font-size: 18px;"><strong style="font-size: 18px;">Constraints:<br></strong></span><span style="font-size: 18px;">1 ≤ n ≤ 10^5<br></span><span style="font-size: 18px;">0 ≤ start[i] ≤ end[i] ≤ 10^9</span></p></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Flipkart</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>Sorting</code>&nbsp;
